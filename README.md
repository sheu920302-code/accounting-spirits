## 怎麼繼續做下去

專案規則都寫在 [`AGENTS.md`](AGENTS.md)。新增精靈時，只要：

1. 照 AGENTS.md 的提示詞模板生成插圖，裁切後放進 `assets/spirits/<slug>/`。
2. 在 `data/spirits.js` 新增一筆資料、在 `data/chapters.js` 登記到對應篇章。

首頁卡片、篇章進度和詳細頁都會自動更新。目前進度與待辦見 [`NOTES.md`](NOTES.md)。
